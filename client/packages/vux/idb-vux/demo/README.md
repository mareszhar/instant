# idb-vux Demo

This demo is a minimal Nuxt app that shows how to run `@mszr/idb-vux` in a realistic app setup.

## Prerequisites

- Instant app ID and env setup (see `.env.example`)

## Setup

```bash
bun install
```

## Run

Start dev server:

```bash
bun run dev
```

Then open `http://localhost:3000`.

## Validate

```bash
bun run validate
```

## Build preview

```bash
bun run build
bun run prev
```
